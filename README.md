# Генерация текста на основе цепей Маркова

Практическое задание по реализации алгоритма генерации текста с использованием цепей Маркова.
Программа анализирует исходный текст, разбивает его на слова и строит словарь цепочек (биграмм или триграмм). На основе этих цепочек генерируется новый текст, имитирующий стиль исходного автора.

## Структура репозитория

markov.py — основной код программы на Python.
tolstoy.txt — исходный текст 1 (Л.Н. Толстой, "Война и мир").
dostoevsky.txt — исходный текст 2 (Ф.М. Достоевский, "Преступление и наказание").
results.txt — примеры сгенерированного текста для разных параметров.
analysis.md — анализ результатов и ответы на теоретические вопросы.
